# Next.js React App

Simple mortgage app built with Next.js and React.

## Setup
```
npm install
```
## Run
```
npm run dev
```

Open http://localhost:3000

## Scripts
`dev` – start development server
`build` – build for production
`start` – run production build
`lint` – run ESLint
`test` – run tests (Jest)
`test:watch` – run tests in watch mode

## Production
```
npm run build
npm run start
```
